# DevOps-Agent

企业级服务端运维 Agent 设计项目，平台与 Agent 模块规划使用 Go。Hermes 仅作设计参考，不属于部署组件、协议接入或源码兼容目标。

- 目标形态：以项目对话组织应用部署、CRONTAB 监控、测试库操作和多云资源管理。Harness 强制子 Agent 审核、命令 DRY-RUN、SQL 语法分析与全量审计。
- 全系统采用“检验阶段 → 执行阶段”，先检验，再执行。人类与 Agent 先检验需求、事实、计划、目标和权限。每次 Bash/SQL 调用都检验展开后的内容、参数、目标、权限和审核；Bash 须有有效 DRY-RUN，SQL 须按目标数据库类型和版本完整分析，适用的人审及 JEV 检验也须通过。全部通过后才能执行。
- 已审核规程不能代替每次调用检验。检验阶段只使用受审核的分析或预演接口，不提前实际操作；必要的试运行也须先检验通过。超出规程范围时修订新版本并重新检验。
- “先检验，再执行”是架构内核，约束所有功能与流程。新功能、规程、适配器和派生处理器须说明检验内容、通过条件、执行范围及失败与恢复方法。
- 密钥剪贴板属于 Agent 工具和全局变量体系，用工具管理敏感内容，核心能力是增、删、改、工具查。编号和非敏感备注作为可见引用；工具查只在受控边界内取用并写入获准目标，不向 Agent 或用户返回明文。任何 Agent 或用户都不能显示、读取或导出保存内容。所有操作遵守“先检验，再执行”及既有授权、审核和审计要求。
- 核心控制服务按模块组织并保持单 Docker 容器；Harness、执行器、底座和监控保持独立进程与权限边界。监控旁路不依赖 Agent Worker。
- GoAgent SDK（下称 SDK）规划为独立、版本化的 Go 模块，负责 LLM 协议编码与请求管理（Chat Completions、Responses、Claude Messages、Gemini Generate Content，以及限域的 GLM/DeepSeek PATCH）、上下文与快照压缩、工具目录与调用、有界 Agent loop/子 Agent、检查点、事件、观测和契约回放。公共类型不暴露厂商类型。
- SDK 公开版本化 `EventType` 字符串常量、脱敏事件和 Hook 接口；可信宿主固定版本注册订阅或允许的 Before 扩展。事件不是授权或审计源；After 只通知、不改返回。Hook 不越过门禁/凭证边界或直接操作资产，操作须申请受控工具；失败和超时有界隔离，已启用的 Before 失败阻断当前阶段，无门禁时 Hook 工具请求不执行。
- 宿主注入模型、会话、工具申请/执行门禁和观测端口。`ModelPort` 可由 SDK 的 `ManagedModelClient` 实现，也可由宿主提供兼容模型服务；宿主自定义 `ModelPort` 须通过同等协议及派生契约验收，不得绕过第三方适配器准入。模型凭证只在受控传输后端注入，SDK 只使用受控端点和密钥编号，任何用户或 Agent 都不能读取 API key 或敏感认证头。SDK 不直接访问平台数据库、Docker、云资源、Bash、SQL 或资产凭证。
- 管理员或可信宿主可登记并固定版本的内建或外部工具（编译模块、HTTP/RPC/MCP 适配器）；Agent 不得自注册或自动启用。所有工具和子 Agent 请求统一经过 `GatedToolRequestPort` 与宿主 JEV/Harness/Executor。缺少门禁时工具全关；宿主执行器强制最终门禁，不信任 SDK 的批准标记。
- 上下文快照和压缩须保留固定约束、工具结果关联及厂商签名/续接状态；摘要不是授权、事实库或审计记录，压缩失败不得覆盖有效快照。
- Go 无类继承。GLM、DeepSeek 等第三方 LLM 适配器必须强制嵌入对应基础协议适配器，并通过接口分派派生行为；复用基础行为，只重写厂商差异。不得改成可选组合或独立完整实现。须登记并固定父适配器与派生版本，并验证重写分派生效。
- TLS、鉴权、门禁和脱敏由不可覆写的框架与宿主控制。其他扩展采用接口与组合；PATCH 不得改安全门禁。
- 按阶段交付并累积复测。可用功能须配齐契约测试、故障恢复、观测、文档和兼容迁移。已知安全、一致性、兼容或恢复缺陷不得发布；需要赶进度时缩小范围。
- 新增宿主接入须通过兼容回归。
- 自研 app/manager 监控按基础解析器和派生处理器（PATCH）组织，覆盖字符串、XML、JSON及二进制/Protobuf；Protobuf 按已登记的 schema、消息类型和版本解析。
- 当前仍处于设计阶段。唯一设计入口是 [架构设计与图](ARCHITECTURE.html)。
- 当前不处理 Hermes 源码；系统仍处于设计阶段，功能尚未实现。
